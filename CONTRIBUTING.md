# Contributing to Clawboard

Thanks for helping. Clawboard is a Claude Code mod written in TypeScript with no runtime dependencies, so it is quick to get running.

## Set up

You need [Claude Code](https://claude.com/claude-code) (developed on 2.1.311) and Node 22.18 or newer.

```bash
git clone https://github.com/SJ-Hariharan/clawboard
cd clawboard
claude --plugin-dir .      # loads the mod from this folder for one session
```

Open the panel with `/clawboard`. While you develop in an interactive session, saving a file reloads the mod.

## Check your change

```bash
npm run check              # claude plugin validate + claude plugin test + asset check
npm ci && npm run typecheck
```

`typecheck` reads the API types Claude Code writes into `.claude-plugin/types/` when it loads the mod from a folder it watches. That folder is git-ignored. Load the mod once in an interactive session first.

The tests (`tests/`) run through `claude plugin test`. UI tests mount the real pane on the `desktop` and `terminal` surfaces against a mocked engine; the rest are plain unit tests. Please add a test for behavior you change, and when you fix a bug, a test that fails without the fix.

## How the code is arranged

`hooks/register.tsx` is the mod's entry. Two rules of the engine's static checker shape the code, so please keep to them:

- `$` is only spelled at a call site (`$.noun.method(...)`). It cannot be put in an object, stored or passed to a function. That is why each hook builds a small `io` object of closures (see `hooks/io.ts`) and the helpers take `io` instead of `$`.
- State atoms are declared in `register.tsx` with literal `plugin` and `key` values, and every key is declared in `types/index.d.ts`.

Crab states are decided in `hooks/classify.ts` from real tool calls; the colony art is in `hooks/crabs.ts`; The Burrow's scan is `hooks/scan.ts`.

## Ground rules

- **Real data only.** Never show a number the session did not report. If a value is not available, say so in the panel. Never derive plan limits from token counts.
- **No fake demos.** Screenshots must come from the running panel. Art generated by `npm run assets` must be labelled as a render.
- **Keep it dependency-free.** The mod has no runtime dependencies; please do not add any without a strong reason.
- **No secrets, no personal paths.** Do not commit keys, tokens, local config or machine-specific files.

## Artwork

`assets/*.svg` and the README art are generated, so edit `scripts/make-assets.mjs` or `hooks/crabs.ts` and run `npm run assets`. CI fails if the committed files are stale. `assets/social-preview.png` is made with `scripts/render-png.swift` (macOS).

To add a hat, shell, skin or color, add it to the lists at the top of `hooks/crabs.ts` and to the drawing code below them, and add it to `tests/crabs.test.ts` if it changes behavior.

## Pull requests

1. Fork and create a branch.
2. Make a focused change, with tests.
3. Run `npm run check` (and `npm run typecheck` if you can).
4. Open a pull request and fill in the template. Say which Claude Code version and surface (desktop, terminal, VS Code) you tried it on.
